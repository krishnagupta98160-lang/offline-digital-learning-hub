# offline-digital-learning-hub
I built a learning hub that needs no internet. Using a Raspberry Pi 3, a microSD card, a power bank, and Kolibri, a free open-source learning platform, I built an Offline Digital Learning Hub for about $60. It creates its own Wi-Fi network. A child opens a browser with a normal phone and finds textbooks, videos, simulations, and quizzes waiting.
# 🌍 Off-Grid Education Ecosystem: Raspberry Pi Hub & EcoBits PWA

> **"No internet, no barriers, just learning, everywhere."**

A low-cost, zero-infrastructure digital learning framework designed to bring offline education and gamified climate literacy to off-grid and underprivileged communities. Built on a strict ~$60 budget using a Raspberry Pi and Kolibri.

---

## 🛠️ Tech Stack & Architecture
* **Hardware:** Raspberry Pi 3/4, microSD card, standard power bank.
* **Core Server:** **Kolibri** (Open-source offline learning platform).
* **Climate PWA:** **EcoBits** (Next.js, TypeScript, Tailwind CSS).

---

## 📂 Repository Structure
* `/ecobits-pwa` — Frontend source code for the EcoBits Progressive Web App.
* `/pi-setup-docs` — Step-by-step documentation for configuring the Raspberry Pi local Wi-Fi AP and Kolibri server.
